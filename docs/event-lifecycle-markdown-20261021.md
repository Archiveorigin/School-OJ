# 场次权限与单题 Markdown 导入

本版替代 `event-completion-20261020.md` 中“截止后隐藏资源、允许撤销完结”的约定，以及 `event-document-import-20261020.md` 中 PDF、本地图片匹配及服务器抓取外链图片的流程。历史审核日志和已保存的题面图片继续保留。

## 状态与权限

| 阶段 | 出题管理人员 | 原访问范围内的参与者 | 提交新代码 |
| --- | --- | --- | --- |
| 草稿、待审核、退回 | 管理本场；仅草稿和退回可编辑，待审核可撤回 | 列表不可见，直接访问也拒绝 | 不可 |
| 未开始 | 查看审核后的完整内容；开始前可撤回重新审核 | 只开放说明；题目、附件、提交记录、排名入口隐藏 | 不可 |
| 进行中 | 查看本场 | 校内考试须确认进入且未提前交卷；团队比赛须在冻结名单和当前团队范围内 | 按原参赛权限开放 |
| 已截止 | 检查成绩，完成必要的人工评分或已有提交评测 | 题目、附件、本人提交与原规则允许的排名仍可读；不可修改测试内容 | 所有人均不可 |
| 已完结 | 历史审核只读；评分、重判和状态变更锁定 | 原列表“已归档”按钮不可进入，从菜单“比赛”检索和查看 | 不可 |

- 只有管理员能确认完结，且必须已截止、无排队/运行中的提交、无待人工评分。
- 完结为最终状态，撤销完结接口被拒绝。旧的考试、比赛详情接口返回 `410 / EVENT_COMPLETED`；浏览器旧书签转到仍需鉴权的归档。
- 到时间只变为已截止，不会自动归档；未审核、撤回或逻辑删除的场次不会自动进入归档。
- 归档沿用原班级、课程和团队可见范围，OI 排名和原先关闭的排名保持原规则。
- 已截止校内考试允许原范围内人员读题和下载图片，无需重新进入考试；提前交卷者在考试仍进行时保持原限制。
- 本场附件按钮与组题、设置同排，按权限从左向右显示；附件弹窗在草稿阶段可管理，其他阶段只读。

## 单题导入

只接收 UTF-8 的 `.md` / `.markdown` 文件，最大 200000 字节，也支持粘贴文本。每次必须恰有一个一级标题。先解析预览，再进入编辑器校对并添加测试点；保存后随整场送审。预览和草稿修改不增加送审版本，实际提交审核才增加一次。

````markdown
# 题目标题

## 题目描述
正文和 $a+b$ 等公式。

## 输入格式
输入说明。

## 输出格式
输出说明。

## 样例 1 · 输入
```text
1
```

## 样例 1 · 输出
```text
2
```
````

样例输入和输出各自使用代码块；输出标题为 `## 样例 1 · 输出`。兼容“输入输出样例 #1 / 输入 #1 / 输出 #1”等常见格式。“说明”“说明/提示”可选，空白不展示。多个一级标题会提示拆为单题，避免把整卷误合并成一题。

图片可写为 `![说明](https://example.com/image.png)`。指向 PNG、JPEG、GIF、WebP 的 Markdown 链接、独立 HTTPS 图片网址也会显示图片；代码块中的文本保持不变。浏览器直接加载原图，不向服务器抓图、不上传本地配图。原站不可用或禁止外链时，页面显示失败提示。图片懒加载并禁止发送 Referer，CSP 仅扩展 HTTPS 图片来源，其余脚本和网络限制保持。

删除 PDF 解析、PDF 预览/裁剪、PDF.js 依赖、图片匹配/上传工具和已无调用方的服务器图片抓取接口。已存储的受保护题包图片仍通过原鉴权接口读取。
