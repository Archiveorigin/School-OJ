# 组题导入与提交版本

## 入口和工作流程

- 团队比赛说明页：组题位于比赛设置左侧，移除下方重复的管理卡片。审核锁定后入口变为查看试卷与审核。
- 组题目录：**导入 Markdown 单题**，支持文件及粘贴内容。
- 试卷工具栏：**导入 PDF 题册**，识别整册并生成逐题处理队列。
- 解析后先核对栏目、公式、样例及图片，再添加测试点并保存。题目与本场附件一起提交整场审核。样例不自动冒充完整测试点。
- 导入队列仅驻留当前页面，逐题保存后才持久化；离开页面、替换文件或提交时会说明未保存题目的处理。保存一题后自动回到下一题，已保存项目禁止重复添加。

## Markdown 规范

使用 UTF-8 编码，最大 200000 字节；一个一级标题表示一道题。推荐格式：

````markdown
# 两数之和

## 题目描述
给出整数 $a,b$，求它们的和。

## 输入格式
一行两个整数 $a,b$。

## 输出格式
输出 $a+b$。

## 输入输出样例 #1
### 输入 #1
```text
1 2
```
### 输出 #1
```text
3
```

## 说明/提示
可选说明；没有内容时省略。
![示意图](images/example.png)
````

同时兼容“样例输入 1 / 样例输出 1”、系统导出格式“样例 1 · 输入 / 输出”、题目背景和多组样例。代码块内部的标题不会当成栏目，公式及未知子标题保留。说明和样例解释不并入样例输出。

## 图片规则

支持内联图片 `![说明](images/a.png)`、引用式图片，以及直接指向 PNG/JPEG/GIF/WebP 的 Markdown 链接。代码块、行内代码及普通来源链接不会被替换。

相对路径会解码 URL 编码、统一目录分隔符、移除开头的 `./`；禁止绝对路径及 `..`。多选本地图片时优先匹配完整路径，再匹配唯一同名文件；重名时由用户指定。HTTPS 外链可点击导入，下载失败时可指定本地图片。

图片校验真实文件类型，按 SHA-256 内容命名为 `assets/<hash>.<实际格式>` 并去重，引用同步替换。单张最大 5 MiB，每题最多 30 张、合计 20 MiB；保存后资源通过已有本场权限接口读取，不依赖原网站持续可用。

外链获取仅允许公开 HTTPS、443 端口。每次重定向均重新校验域名和全部解析地址，实际连接固定到已验证 IP，保留 TLS 主机名校验；拒绝内网、回环、链路本地、保留地址、账号信息、HTML/SVG。限时、限大小、限跳转和按用户限流。预览下载不修改场次，最终保存仍重新核验权限、状态与并发版本。

## PDF 规则及适用边界

PDF 在浏览器 Worker 中读取，按需加载解析组件，原始 PDF 不发送到解析服务器。字体、字库和解码资源由本站提供。每次最多 20 MiB / 60 页，图片最多合计 40 MiB；取消读取或离开后释放解析任务。

支持文字版题册、单栏正文，标题如 `Problem A. 陶陶摘苹果` 或 `题目 1：两数之和`；忽略封面、页眉页脚与输入输出文件元数据，解析时间/内存限制、中英文章节、连续多行样例及并排样例表。根据字符位置恢复简单上下标，避免把 `2³¹` 读成 `231`。

内嵌位图按页面变换位置提取，随相应章节保存；原页始终可用于校对。矢量插图、复杂公式或无法自动还原的内容，可在原页拖动框选，或用百分比坐标精确截取，再插入选定栏目。扫描件、任意双栏正文和所有数学排版不承诺自动识别，需先转成支持的文字版格式；保存前须确认已对照原文核对。

## 版本与兼容性

`submission_version` 仅在一次整场送审事务成功时加一；普通题目、设置、附件编辑及批准、退回不增加它。重复或并发提交通过行锁及并发令牌拒绝，不产生重复版本。审核记录关联提交版本。

`review_revision` 继续作为内部并发令牌，每次修改递增，保护多人编辑和大文件上传。前台不显示这两个计数，也不显示题目固定版本数字。迁移 `034_event_submission_version.sql` 根据已有送审日志回填；没有日志的旧场次保持零，不编造历史版本。既有状态链、截止后的访问隔离、管理员完结和原访问范围保持原有规则。

## 验证方式

本地提供的 Markdown 与 PDF 通过可选环境变量 `OJ_IMPORT_MARKDOWN_FIXTURE`、`OJ_IMPORT_PDF_FIXTURE` 参与验收，原始文件不提交到代码仓库。PDF 验收核对十道题、二十组完整样例及关键上下标。自动化同时覆盖 Markdown 图片与代码保护、路径歧义、SSRF/重定向/大小限制、并发送审计数、迁移回填、浏览器桌面与手机端导入及原有考试/比赛权限流程。
