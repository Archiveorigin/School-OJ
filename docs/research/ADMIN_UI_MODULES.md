# 后台管理界面模块分析

本文记录第 3 版后台主题落地时的真实功能边界。界面只展示当前 API 和权限模型能够支持的数据，不引入无后端支撑的统计或审批能力。

## 信息架构

| 分组 | 模块 | 路由 | 使用角色 | 核心功能与主操作 |
| --- | --- | --- | --- | --- |
| 工作台 | 教学概览 | `/admin` | 管理员、教师 | 汇总考试草稿、已创建考试、真实待审批事项与近期管理动态；继续草稿或进入考试详情 |
| 教学组织 | 课程管理 | `/admin/courses` | 管理员、教师 | 创建/编辑/归档课程，维护课程成员、班级和学生 |
| 教学组织 | 班级管理 | `/admin/classes` | 管理员、教师 | 创建/编辑/归档班级，切换当前班级，维护和批量导入学生 |
| 教学组织 | 考试管理 | `/admin/exams` | 管理员、教师 | 创建考试，查看考试详情、榜单和完成情况，导出成绩，人工阅卷，删除考试 |
| 教学组织 | 考试发布 | `/admin/exams/new` | 管理员、教师 | 三步完成基本信息、题目与分值、发布确认；支持浏览器草稿、预备题和考试内新建题 |
| 内容与评测 | 预备题库 | `/admin/prepared-problems` | 管理员、教师 | 管理未公开题目、题目包、测试点和发布范围 |
| 内容与评测 | 出题管理 | `/admin/problem-authors` | 管理员 | 审核出题资格申请、题目发布申请，撤销出题权限或已通过题目 |
| 内容与评测 | JPlag 查重 | `/admin/plagiarism` | 管理员、教师 | 按课程任务启动相似度分析并查看任务状态与报告 |
| 系统治理 | 用户与权限 | `/admin/users` | 管理员 | 创建、编辑、删除账号，调整角色并重置密码 |
| 系统治理 | 审计日志 | `/admin/audit-logs` | 管理员 | 查看关键资源与权限操作记录 |

## 第 3 版主题适配决策

- 保留“学术型浅色工作台、深蓝校徽区、宋体展示标题、细分隔线和克制红色发布动作”的主视觉。
- 用现有校园图片作低对比度头图，不新增不可维护的手绘装饰资源。
- 将原卡片入口首页替换为“考试发布计划 + 发布准备”双栏主任务区；课程、班级等模块仍通过左侧分组导航直接到达。
- 草稿来自 `school-oj-exam-create-draft` 浏览器存储；没有草稿时不伪造待发布考试。
- 管理员待办只读取出题资格申请和题目审批接口；教师不请求管理员接口。
- 管理动态优先读取审计日志；教师界面回退为近期考试安排。
- 考试创建保留原有三步组件和全部业务校验，仅移除重复的前台侧栏并嵌入后台壳层。
- 旧 `/exams/new` 入口保留为兼容重定向，课程上下文通过 `course_id` 查询参数传入新路由。

## 功能不适配时的处理原则

- 设计图中的“确认发布”不能从后台首页直接执行；首页只能继续草稿，最终创建仍在发布确认步骤完成。
- 设计图中的固定考试数量、审批数量和动态均替换为真实接口返回值或明确空状态。
- 教师与管理员共享教学模块，但用户、审计和出题审批继续遵循现有管理员权限，不因视觉统一而扩大授权。
- 考试结束后的完成情况、导出、阅卷与榜单仍由考试管理列表承载，不挤入发布流程。
