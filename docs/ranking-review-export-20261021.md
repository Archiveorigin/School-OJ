# 实时排名、截止审核与榜单导出

## 计分和刷新

用户确认统一 ACM 规则：编译错误不计罚时；按通过题数降序、总罚时升序、最后一次首次通过时间升序排序；仍相同则并列。并列采用 `1、1、3` 名次，姓名/用户 ID 仅稳定显示顺序，不影响竞技名次。历史场次重新读取时也使用修正后的计算规则。

- ACM：每题首次通过前的有效错误每次加 20 分钟，排队、评测中、待人工评分、系统异常、编译错误均不计错误罚时。后续重复提交不改变首次通过时间。
- OI：每题最后一次提交计分，按总分、满分题数排序；相同并列。历史通过、最后未通过的题目不能继续计为满分题。
- IOI：每题最高分，按总分、满分题数、最后有效得分时间排序；相同并列。
- 仅计入 `[开始时间, 截止时间)` 内的提交，以提交时间界定，不以评测完成时间界定。
- 考试、团队比赛榜单和管理端共用后台计分方法。页面每 5 秒刷新，截止后继续更新迟到的评测、重判和人工评分结果，直到管理员确认完结或离开页面。
- OI 排名及封榜期间的实时信息仍遵循原参与者权限；管理端可以查看完整排名。

## 审核和导出

在整场审核/组题工作区增加“成绩与排名”，在进行中、已截止、已完结显示。管理人员可查看真实成绩和待评测、待人工评分、系统异常数量。

只有已截止/已完结且评测、人工评分完成、无判题系统异常时，才能导出完整排名。若下载前发生了新重判，服务端再次验证并返回 409；不依赖前端按钮判断。系统异常也会阻止确认完结。

- Excel：冻结表头和参赛者列，自动筛选，数值名次，保留学号前导零；简洁标题、截止时间、人数和审核状态，逐题颜色区分最早通过、通过、未通过、未提交。
- HTML：独立文件，无脚本、外链资产或登录依赖；可通过浏览器打印保存为 PDF，横向版式、重复表头。
- ACM 显示解题数、罚时和逐题 `+错误次数 / 首次通过分钟`；OI/IOI 显示实际得分和满分题数。
- 已截止导出标注“待审核”；已完结导出标注“已确认”。导出不会自动修改场次状态。
- 导出采用留白、浅色表头和紧凑成绩色块，移除赛制说明段落、技术标识和冗余元数据；下载文件名为“排名表-场次编号”。
- 导出始终使用完整后台结果，不受页面筛选、搜索或参赛者封榜影响。仅本场有管理权限者可下载；删除场次返回 404。
- 现有考试 Excel/Markdown 报表不再固定使用 IOI，改为本场真实赛制，并读取绑定题目版本。
- 排名与完成检查在同一个 PostgreSQL `REPEATABLE READ READ ONLY` 快照中读取，避免导出混合更新前后的成绩。
- 所有下载响应 `private, no-store`；HTML 对名称等内容转义，Excel 使用内联字符串保存姓名、学号，不生成用户输入公式。

新增接口：

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/event-papers/:kind/:event_id/ranking` | 管理端完整排名和结算状态 |
| GET | `/event-papers/:kind/:event_id/ranking/export?format=xlsx` | Excel 榜单 |
| GET | `/event-papers/:kind/:event_id/ranking/export?format=html` | 可打印 HTML 榜单 |

## 验证

- PostgreSQL/Redis 集成测试覆盖考试、团队比赛的 ACM/OI/IOI、截止边界、CE 罚时、并列名次、迟到评测、人工评分、系统异常、旧报表、越权访问、完结标记和删除场次。
- 前端覆盖截止后自动刷新、离开停止、评分完成启用导出，以及切换展示模式保留并列名次。
- `tests/e2e/ranking-review-qa.mjs` 使用隔离浏览器测试数据库，执行 6 条真实流程，验证自动刷新、按钮可用状态、Excel/HTML 下载及桌面/手机布局，并打印 PDF。
- 新接口已更新 OpenAPI 和生成客户端。没有新增数据库迁移。

视觉参考：[2025 ICPC World Finals 官方榜单](https://worldfinals.icpc.global/scoreboard/2025/finals/)。ACM 排序与编译错误处理参考 [ICPC 官方区域赛规则](https://icpc.global/regionals/rules)，并由用户明确确认应用到本项目。
